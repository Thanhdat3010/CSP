📖 WHAT IS CHARM?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CHARM = Cluster-Aware Hard Example Mining

New data augmentation for camouflaged object detection that:

  1. PRESERVES objects (100% unchanged from original image)
  2. FINDS hard negatives (difficult examples in same cluster)
  3. BLENDS background (replace background with hard negative)
  4. SMOOTHS boundary (realistic, no artifacts)

Result: Model learns to detect objects in challenging contexts
        while maintaining object detection confidence.

Expected Performance Improvement:
  • Precision: 0.596 → 0.55-0.65 (stable)
  • Recall: 0.148 → 0.20-0.25 (+35-70%)
  • mAP50: 0.166 → 0.18-0.22 (+8-32%)

STEP 1: Generate dataset locally
────────────────────────────────
In PowerShell at d:\Code\CSP:

  .\charm_quickstart.bat

This will:
  1. Generate CHARM dataset (10-15 min)
  2. Verify quality
  3. Done! Dataset ready for upload


STEP 2: Train on Colab
──────────────────────
1. Upload data/COD10K-CHARM/ to Google Drive
2. Mount in Colab notebook
3. Run YOLOv8 training:

  !yolo detect train \
      model=yolov8s.pt \
      data=/path/to/COD10K-CHARM/data.yaml \
      epochs=100 \
      batch=64


Expected Output (Step 1):
  ✅ data/COD10K-CHARM/train/images/  (24,320 images)
  ✅ data/COD10K-CHARM/train/labels/  (24,320 labels)
  ✅ data/COD10K-CHARM/val/           (2,026 images)
  ✅ data/COD10K-CHARM/data.yaml      (YOLO config)

🔧 PARAMETERS (Advanced)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Manual dataset generation with custom parameters:

  python src/augmentations/charm/generate_charm_dataset.py ^
      --partition_dir data/COD10K_Partitioning ^
      --output data/COD10K-CHARM ^
      --margin 10 ^
      --smooth_kernel 15 ^
      --top_k_hard 3 ^
      --split_ratio 0.8

Parameters:
  --margin            Safety buffer around object (default: 10 pixels)
  --smooth_kernel     Gaussian blur kernel size (default: 15)
  --top_k_hard        Number of hard negatives per image (default: 3)
  --split_ratio       Train/val split ratio (default: 0.8)

Q: "How long does generation take?"
A: 10-15 minutes on CPU (depends on disk speed)

Q: "How long does training take?"
A: ~1.2 hours on A100 GPU (depends on batch size)

Q: "Can I adjust K (hard negatives)?"
A: Yes! Use --top_k_hard 1-5 (default 3)

Q: "What if I only want originals?"
A: Use --top_k_hard 0 (but why?!)

Q: "Can I use different margin?"
A: Yes! Use --margin 5-20 (default 10)

See CHARM_README.md for more troubleshooting
